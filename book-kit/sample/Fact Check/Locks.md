# Locks

The one record of whether a chapter is locked (`Methodology/Chapter Close-Out Procedure.md`). One row per lock or unlock, newest last: 🔒 locked, 🔓 unlocked. The last row for a chapter is its state; a chapter with no row is unlocked. **Do not edit this file by hand.** `tools/lock.py` is the only writer of this file; it logs each change in the event log. Rows are never edited, so the table is the chapter's lock history, and the event log records each change as well.

- `tools/lock.py unlock NN --by production --note "<the author's ruling and the reason>"`
- `tools/lock.py lock NN --by production` — refuses until `tools/check-lock-ready.sh NN` passes
- `tools/lock.py status` — each chapter and its state

Reopening a locked chapter is the author's decision.

**Columns:** `chapter` (two digits) · `state` (🔒 or 🔓) · `date` · `by` (the role) · `note` (for an unlock, the reason and the author's ruling).
