# Punch List

The open items that are neither a card nor an ask: a search to run, an illustration to find, a pointer to repair, a fault for later. Production keeps this file; any role may append an item for Production in `Handoffs/Production.md`'s Inbox. When an item is done, remove it here and record what was done where Roles.md says (the ledger, a commit, the hand-off).

**Format.** One item per line: `- [ ] ChNN — <what is open, with Ch##/L## where there is one> (<date>, <who found it>)`. Name the chapter as `ChNN`, `Ch. N` or `Chapter N` so `tools/check-lock-ready.sh` can find it: **an open item that names a chapter blocks that chapter's lock** (the author: *"If it is open it is blocking."*). Items for the whole book go under **Book-wide**.
