# Watcher directives

Written by the scheduled Watcher (`Fact Check/Watcher/Watcher Protocol.md`). Each run that finds a fault adds one directive below, numbered `W-YYYY-MM-DD-NN`, with the rule broken, the evidence, and the steps for the role that owns the fault. The Managing Editor routes each directive at session open and writes a **Routed:** line under it. A role reports under its directive, under its own "<Role>'s report" heading, and writes nowhere else in this file.
