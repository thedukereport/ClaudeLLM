# Findings Register

Each finding the Fact-checker or the nightly agent makes, one row, in the turn it is found (`Fact Check/Agent Protocol.md`). The same finding goes into the chapter's ledger in the same step. Before writing a row, read the chapter's rows here and its ledger: a finding already here is never written twice.

**Columns:**

- **coordinate** — `Ch##/L##`, or the note slug.
- **phrase** — copied from the line, distinctive enough to find it after the line moves.
- **finding** — opens with the check type (FOOTNOTE, SCAN-banned-word, SCAN-epistemic, SCAN-nominalization, SCAN-abstract-noun, SCAN-unspecified-verb, SCAN-completeness, SCAN-<principle>, FACT, FACT-URGENT, GLOSS, GLOSS-URGENT, LEAK), then the source read, where in it, the words found, the date read, and for a negative the coverage of the search.

A row closes when its card is applied, or when the author declines it; then it moves to **Closed** with one line of reason, and nobody raises the same line again unless the line changes.
