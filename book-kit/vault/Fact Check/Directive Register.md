# Directive Register

Each comment of the author's that asks for work is a directive, and gets a row here in the turn it is given, quoting the author's words whole (Standing Rules §4). Written by the Managing Editor; any role that receives a directive in its own chat adds the row in the same turn. An item does not close while a question of the author's in it is unanswered. The Watcher reads this file and reports a directive closed with no evidence, and a directive with no row.

**Columns:**

- **id** — `D1`, `D2`, … never reused.
- **given** — the date and time, and the chat it was given in.
- **the author's words** — verbatim, whole.
- **for** — the role it is for.
- **what was done** — the file, block id, commit or event hash that shows it done.
- **state** — OPEN, DONE (with the evidence named) or ANSWERED (a question, with the answer).
