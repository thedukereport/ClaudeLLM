# Hand-off — Managing Editor

The Managing Editor's notes to its next session, and the one place other roles leave it work. The first line above is the role's `WORKING:` line: `WORKING: <chapter or task> — <time>` while a session works, `WORKING: nothing` when it ends. Only the Managing Editor writes this file, except the **Inbox**, where any role appends an item and only the Managing Editor removes it.

Keep this file under 2,000 words. History goes to a dated log file beside it, `Handoffs/Managing Editor — log YYYY-MM.md`: when a section here is done, move it there whole. A hand-off that grows past what a new session can read at once stops working as a hand-off.
