# Scratch Notes

The author's place to put an idea down without interrupting a chat. Write anything, anywhere below the line, in any form.

The Managing Editor reads this file each session and routes each item: to a role's hand-off Inbox, to `Punch List.md`, to `Fact Check/Asks.md`, or to a chapter's queue in `Fact Check/Ship Triage.md`. A routed item keeps its text and gets a mark at the end of its line: `→ routed to <file>, <date>`. The Managing Editor writes only the routing marks; the words are the author's.
