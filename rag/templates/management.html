➕ Update Index

Add new books (and drop removed ones) without re-indexing everything. Only new or changed books get re-embedded; your tuned settings (nlist 1024, nprobe 128, cosine) are preserved. Takes minutes for a handful of books instead of hours.

⚠️ After the update finishes: the Claude MCP server keeps its own copy of the index in memory — new books stay invisible to Claude's searches until you restart it. Restart the Claude Desktop / Cowork session (which relaunches the MCP server), then ask Claude to search for one of the new books to confirm. This web UI picks up the new index on its own.

🩺 PDF Health Check

Scan PDFs for corrupted streams (the "Data-loss while decompressing" issue) without re-indexing. Incremental: unchanged files (per scan_manifest.json) are skipped, so after the first full run only new or changed files get scanned — seconds, not minutes. Results are written to problem_pdfs.txt.

Typical session: added books? → Update Index (then restart the MCP server — see above). Want a corruption check? → Scan Library on Incremental. The first incremental scan builds scan_manifest.json (~12 min); after that it only scans new/changed files — seconds. Verify re-hashes unchanged files to catch silent replacements (use after restoring from backup). Full ignores the manifest.

🔄 Refresh Work Queues

Rebuild the OCR and exclude queues from what is actually on disk. The queues were hand-maintained, so any book added afterwards was never considered by any pass — 65 books sat with no text layer while the OCR queue reported empty. This asks the library instead of a stale list. Takes about a minute. Run it whenever you add books.

Maintenance Tips

    

        

            💾
            

                Backup Your Index
                
Keep alexandria.index and alexandria_metadata.json safe. The index takes time to build but can be regenerated.

            

        

        

            📚
            

                Adding Books
                
If you add new books to your collection, go to the Indexing page and rebuild the index to include them.

            

        

        

            ⚡
            

                Performance
                
Search is faster on GPU. If you have CUDA or Metal, make sure you're using the GPU-accelerated version.

            

        

        

            🎯
            

                Better Results
                
Use larger embedding models (all-mpnet-base-v2, all-roberta-large-v1) for higher quality search results, at the cost of speed.
